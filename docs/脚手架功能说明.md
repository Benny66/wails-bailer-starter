定位：**Wails v + Vue3 + Vite + Element Plus + Go 后端**
## 脚手架内置能力清单（贴合你的业务场景）

### 后端 Go 层

1. 自动 WebView2 检测 + 引导安装（Windows 专属，Wails 启动钩子）
2. 单实例锁：防止重复打开客户端（B 端刚需）
3. 系统托盘 + 最小化到托盘、右键菜单、双击恢复窗口
4. 本地 SQLite 封装（gorm，自带迁移，示例表：资产表）
5. 全局日志封装：文件日志 + 控制台日志，日志分级、自动轮转
6. 基础配置模块：`config.json`，读写本地配置文件
7. 原生对话框封装（选择文件夹、选择文件、消息弹窗）
8. 自动更新基础骨架（本地版本校验，下载二进制，windows/mac 更新框架，**不做复杂差分更新**）
9. 优雅关闭：退出时释放数据库连接、goroutine 回收，避免进程残留
10. 全局异常捕获，崩溃日志保存

### 前端 Vue3 层

1. Vite + Vue3 + Element Plus + Vue Router + Pinia
2. 基础 B 端布局：侧边菜单 + 顶部导航 + 内容主区域
3. 自动生成 wails bindings TS 类型，前端直接调用 Go 方法
4. 示例页面：首页仪表盘、资产列表、系统设置页
5. 封装请求工具（这里是调用 Go 后端，不是 http）
6. 表单、表格、分页基础组件示例
7. 开发环境热更新（Wails 自带 vite 热更）

### 打包 & CI（GitHub Actions）

1. 打包脚本：`wails build` 脚本，Windows/macOS/Linux
2. GitHub Actions CI：提交代码自动编译产物（exe/dmg/appimage）
3. .gitignore 预配置（go mod、node、编译产物、日志、sqlite 数据库）
4. 内置 `wails.json` 预配置（窗口大小、标题、图标）
5. README：详细文档、环境准备、开发、打包、WebView2 部署说明

### 额外工具脚本

- `scripts/webview2-check.ps1`：WebView2 检测离线安装辅助脚本
- `scripts/release.sh`：版本号管理，打包 + 生成 release 说明
