定位：**Wails v2 + Vue3 + Vite + Element Plus + Go 后端** 的桌面客户端基座。

> 定位一句话：**只给管道，产品面下游自己长。**
> 本基座提供窗口生命周期、数据层、配置、日志、原生能力、生成器、打包发布，
> 以及它们之间的**契约**；表格/表单/进度条/toast 等产品面由下游按需自建，基座不预置。

## 基座内置能力清单

### 后端 Go 层

1. 单实例锁：防止重复打开客户端；二次启动唤起已有窗口
2. 系统托盘 + 右键菜单 + 双击恢复窗口（**仅 Windows/Linux**；macOS 因 Wails v2
   的 NSApplication delegate 与所有 systray 库冲突，关闭即退出）
3. 本地 SQLite 封装（gorm，启动时按 `AllModels()` 自动迁移）
4. 全局日志封装：文件 + 控制台双写，分级、按大小轮转（5MB × 3 份）
5. 基础配置模块：`config.json` 读写（当前字段：主题）
6. 原生对话框封装（选择文件/目录、保存、确认）
7. 优雅关闭：退出时停托盘、落盘配置、释放数据库连接
8. 崩溃捕获：`internal/crash` 提供 panic 落盘（**供业务在长驻 goroutine 中显式包裹使用**）
9. **管道契约**（`openspec/specs/pipeline-contract/`）：
   - 错误协议：`internal/apperr` + Wails `ErrorFormatter` → 前端拿到 `{code, message}`
   - 分页协议：`internal/page` 的 `Request` / `Result[T]`
   - 事件协议：`internal/event` 的 `<domain>:<action>` 与 payload 约定

### 前端 Vue3 层

1. Vite + Vue3 + Element Plus + Vue Router（hash 模式适配 `file://`）+ Pinia
2. 基础 B 端布局：无边框标题栏（分平台）+ 侧栏菜单 + 内容主区域 + 主题切换
3. 自动生成 wails bindings TS 类型，前端直接 `import` 调用 Go 方法
4. 错误归一化包装 `src/lib/invoke.ts`（把 Go 的结构化错误还原为 `{code, message}`）
5. 开发环境热更新（Wails 自带）

> **不含**：示例业务页面、表格/表单/分页的 UI 组件封装——这些属于产品面，由下游自建。
> `_example/` 是生成器模板与**可抄的契约用法范例**，不是产品页面。

### 打包 & CI（GitHub Actions）

1. 打包脚本 `scripts/package.sh`：`make package os=windows|macos|linux`
   - macOS：产出**美化 dmg**（Applications 软链 + 背景图 + 图标定位 + 回读校验）
   - Windows：NSIS 安装器（`scope=user|machine`）；无 makensis 时明确提示并降级
2. `.gitignore` 预配置（go mod、node、编译产物、日志、sqlite 数据库）
3. 内置 `wails.json` 预配置（窗口大小、标题、图标）
4. CI：提交/PR 时跑静态检查 + 三平台编译（产物上传为 artifact；**CI 不跑打包**）
5. README：环境准备、开发、打包、安装模型、已知限制

### 额外工具脚本

- `scripts/gen.sh`：模块生成器（`make gen name=<module>`），产出符合管道契约的
  model + service + 绑定 + 页面 + 路由 + 菜单
- `scripts/verify-gen.sh`：生成器端到端验证（`make verify-gen`，临时沙箱）
- `scripts/release.sh`：版本号管理，打包 + 生成 release 说明
- `scripts/smoke.sh`：冒烟测试（构建 → 启动 → 断言 → 清理）
