# 代码规范

## Go 代码规范

### 命名

| 元素 | 规则 | 示例 |
|---|---|---|
| 包名 | 小写、单数、简短 | `services`、`models` |
| 文件名 | snake_case | `user_service.go` |
| 结构体/接口 | 大驼峰 | `UserService`、`BaseModel` |
| 方法/函数 | 大驼峰（导出）小驼峰（私有） | `GetUserList`、`getUserPermissionCodes` |
| 变量 | 小驼峰 | `pageSize`、`roleIDs` |
| 常量 | 大驼峰或全大写 | `MaxPageSize` |

### JSON Tag

所有模型字段 MUST 带 snake_case 的 JSON tag：

```go
type User struct {
    BaseModel
    Username string `gorm:"uniqueIndex;size:50;not null" json:"username"`
    RealName string `gorm:"size:50" json:"real_name"`
}
```

### 错误处理（管道契约）

- 错误 MUST 显式处理，禁止忽略（`_ =` 需有注释说明）。
- 业务错误 MUST 经 `internal/apperr` 构造，**不得**用 `errors.New` / `fmt.Errorf`
  直接造（否则前端拿不到结构化 `code`——由护栏 `TestBindingsUseAppErr` 强制）：
  - 记录不存在：`apperr.NotFound("xxx不存在")`
  - 入参非法：`apperr.Validation("...")`
  - 状态冲突：`apperr.Conflict("...")`
  - 其他系统错误：`apperr.Wrap(err)`（归一化为 `internal`，原文留在 `Detail`）
- 前端经 `frontend/src/lib/invoke.ts` 的 `invoke()` 归一化为 `{code,message}`，据 `code` 分流。

### 列表与分页（管道契约）

- 列表类绑定方法 MUST 返回 `page.Result[T]`，**不得**返回裸切片。
- 分页参数 MUST 经 `page.Request.Normalized()` 归一化后再查库。
- 页大小上下界（`DefaultPageSize` / `MaxPageSize`）唯一真相在 `internal/page`。

### 事件（管道契约）

- 事件名 MUST 为 `<domain>:<action>`（domain 与业务模块名一致）。
- 进度类 payload MUST 含 `done`/`total`；结束类 MUST 含 `ok`。

> 以上三项即「管道契约」。完整规格见 `openspec/specs/pipeline-contract/`。

## Vue 代码规范

### 命名

| 元素 | 规则 | 示例 |
|---|---|---|
| 组件文件 | PascalCase | `UserList.vue`、`Layout.vue` |
| 页面目录 | kebab-case | `views/system/user/` |
| JS 模块 | camelCase | `request.js`、`format.js` |
| 组合式函数 | useXxx | `useAppStore` |
| 变量 | 小驼峰 | `userList`、`loading` |

### 组件风格

- 使用 `<script setup>` 语法。
- 模板里复杂表达式抽成计算属性或方法。
- 每个页面组件：`<template>` → `<script setup>` → `<style scoped>` 三段式。

### 状态管理目录

MUST 统一使用 `stores/`（Pinia 约定），禁止 `store/` 单复数混用。

## 前端 JS 模块规范

- 工具函数导出用命名导出，一个文件一个职责。
- 调用 Go 后端**直接 import `frontend/wailsjs/go/main/App` 的绑定函数**（Wails 自动生成），
  不经过 HTTP 层；错误处理经 `src/lib/invoke.ts` 的 `invoke()` 包装。

## 通用规范

- 注释使用中文（项目编码语言为中文）。
- 提交前移除 `console.log`、调试代码。
- 不提交数据库文件、构建产物、依赖目录（见 `.gitignore`）。
