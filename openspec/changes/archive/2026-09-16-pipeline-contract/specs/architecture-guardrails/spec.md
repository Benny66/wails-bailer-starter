# architecture-guardrails (delta)

## MODIFIED Requirements

### Requirement: 护栏必须感知自己瞎了
任何用正则/AST 解析源码做断言的护栏，解析到 0 个结果 MUST 报错而非静默通过；
并附「写法可能已变更，请同步更新护栏解析规则」。本要求 MUST 覆盖新增的契约护栏，
且护栏清单 MUST 与生成器/契约定义保持单一真相（不得两处硬编码同一清单而互不校验）。

#### Scenario: 契约护栏解析到空
- **WHEN** 契约护栏无法在绑定文件中解析到目标方法
- **THEN** 护栏失败并提示校准方式，不静默通过

#### Scenario: 清单单一真相不漂移
- **WHEN** 生成器依赖的锚点/契约清单被修改
- **THEN** 存在断言保证护栏侧清单与之相等，漂移会致失败
